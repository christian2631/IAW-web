# Práctica 2: Repositorios Remotos y Colaboración

## Descripción del Proyecto
Este repositorio corresponde a la práctica de la asignatura **Implantación de Aplicaciones Web (IAW)** del ciclo formativo *Administración de Sistemas Informáticos en Red (ASIR)*. El objetivo principal es aprender a gestionar repositorios remotos y trabajar de forma colaborativa en equipo.

### Objetivos de la Práctica
* Configurar repositorios remotos con Git.
* Realizar flujos de trabajo sincronizados mediante `pull` y `push`.
* Documentar proyectos técnicos empleando sintaxis **Markdown**.

## Pasos Realizados
1. Vinculación del repositorio local con el repositorio remoto del compañero.
2. Sincronización de ramas y descarga de cambios previos mediante `git pull`.
3. Creación de la estructura de carpetas y documentación del proyecto.

## Recursos y Enlaces
Para consultar la sintaxis oficial y comandos avanzados, visita la [documentación oficial de Git](https://git-scm.com/doc).

## Comandos Utilizados
| Comando | Función |
| :--- | :--- |
| `git remote -v` | Muestra las URLs de los repositorios remotos configurados |
| `git pull origin rama2` | Descarga y fusiona los cambios de la rama remota |
| `git add .` | Añade todos los archivos modificados al área de preparación |
| `git commit -m "mensaje"` | Guarda una instantánea de los cambios en el historial local |
| `git push origin rama2` | Sube los commits locales al repositorio remoto en GitHub |

## Ejemplo de Flujo de Trabajo
```bash
git status
git add .
git commit -m "Creado README inicial del proyecto."
git push origin rama2
```
